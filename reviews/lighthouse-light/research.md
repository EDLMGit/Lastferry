# Lighthouse light technique notes

Read for this focused pass on 2026-10-23. APIs were checked against the installed Three.js 0.186.1 source; no package or renderer upgrade is involved.

- [John Chapman, Good Enough Volumetrics for Spotlights](https://john-chapman-graphics.blogspot.com/2013/01/good-enough-volumetrics-for-spotlights.html) supplies the inexpensive open-cone principle: additive light with depth testing, disabled depth writes, distance attenuation and view-normal edge attenuation. It also explains source-glow and intersection limitations. This is an appearance proxy, not complete participating-media transport.
- [Three ShaderMaterial](https://threejs.org/docs/pages/ShaderMaterial.html) and [Material](https://threejs.org/docs/pages/Material.html) document shader uniforms and blending/depth/side controls. Installed ShaderMaterial defaults to a single pass; the effect retains that explicit choice. With non-premultiplied additive blending, source alpha scales the added RGB. Each of the cone's front/back surfaces receives half the strength budget; one draw still has transparent overdraw.
- [Three Color Management](https://threejs.org/manual/pages/color-management.html) describes the linear working colors and custom shader output conversion. The new tint is a Three Color converted from the warm palette; the existing tone-mapping and color-space chunks remain. Exposure and the rest of the scene are unchanged.
- [Three OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html) documents the current projection. Last Ferry adapts Chapman's view-direction principle to parallel rays: transform normals to view space, normalize again in the fragment shader, and use the absolute Z component against a constant view direction. No perspective eye vector is formed from fragment position.
- [NVIDIA GPU Gems 3, chapter 13](https://developer.nvidia.com/gpugems/gpugems3/part-ii-light-and-shadows/chapter-13-volumetric-light-scattering-post-process) is background for the unselected screen-space scattering approach. Its additional image sampling and compositing are outside this one-effect pass.

The existing open CylinderGeometry has continuous analytic seam normals. Its narrow source is UV.y=0, and the far ring is UV.y=1 after the mesh's existing rotation/translation. The replacement uses only longitudinal UV distance, fades fully before the far rim, and removes circumference stripes and the silhouette opacity floor. No imported demo code, external texture, noise, extra shell or post-process is used.
