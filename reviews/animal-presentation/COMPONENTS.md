# Passenger choices and the arrival shelf

The shared native choice button keeps its 62px minimum height and reserves a 54px cameo for the head/chest view. Both name and exact cost remain live at 16px. The tick is separate from the face; selected and unselected controls use the same layout. A delayed or failed image leaves the neighbor's initial in the cameo beside their full name. The camera, selection/commit handlers and transfer-sheet placement were not changed.

Arrival now reads the **arrival** derivative of each real rescued identity. The old tall, empty outlined recess was removed. Complete figures stand on a continuous timber lip per row, with soft foot contact and a live name directly beneath. Three figures share one shelf; four use pairs and six use two groups of three. Narrow/notice states reserve less image space before affecting the text or action targets. Reduced Motion, lanterns, storage notice, Details and native dialog ownership keep their previous implementations.

## Original findings

1. The first proposed setup for six real waiting neighbors did **not** remain playable: it left eight spaces offshore as Beacon Reef narrowed the remaining delivery capacity to six at action four. The production game correctly rejected further actions. [Original run](originals/ui/staging-attempt.json). We kept the real four-person transfer, verified all six choices in a labeled layout specimen, and preserved the rules.
2. The first gallery check found a preexisting six-pixel page overflow at 320: the long ferry-roster developer select reached x=326. All choice text fit. A maximum width on gallery panel selects contained it; the final three viewports pass. [Original measurement](originals/ui/gallery-width-first.json).
3. The earlier arrival-image timing test intercepted a bare filename; after a warm Vite asset refresh the beaver URL had a timestamp query, so the image loaded immediately. [Original result](originals/ui/timestamp-route-attempt.json). Image-only route matching now includes the correct profile and permits cache keys. The final three-case run passed. This was a test interceptor issue, not an application loader change.

No physical Android/iOS, spoken screen reader or human listening claim follows from these checks. The gallery and arrival fixture don't award mastery or simulate a live rescue.
